# LAI 인터랙티브 시뮬레이터 프로토타입 스펙 (High-Fi)

## 📌 개요
Loss Avoidance Index(LAI)를 핵심 지표로 활용하여, 사용자가 자신의 비즈니스 변수($T$, $CR$, $AVC$)를 직접 조작하고 그에 따른 '잠재적 손실 비용 감소' 효과를 실시간으로 체감할 수 있는 컴포넌트.

## 🖼️ 레이아웃 구조 (Desktop View)
1.  **좌측 영역 (Inputs & Controls):** 변수 조절 슬라이더 3개 배치. 각 슬라이더 아래에 해당 변수의 비즈니스 의미를 간결하게 설명하는 툴팁/텍스트를 배치.
2.  **중앙 영역 (The Core Visualization):** LAI 변화 그래프가 가장 크게 자리 잡으며, 실시간 데이터 흐름 애니메이션이 배경을 깔고 지나감.
3.  **우측 영역 (Outputs & Storytelling):**
    *   **최상단:** 현재 LAI 점수와 예상 손실액 ($X_{Pain}$)의 대시보드 위젯 배치.
    *   **중간:** 데이터가 변하는 과정을 설명하는 동적 텍스트(Storytelling) 영역 (D.AAL 엔진이 작동하는 과정 설명).
    *   **하단:** 최종적으로 '성장 로직'을 담은 Call-to-Action 버튼 세트 배치.

## 💡 핵심 인터랙션 플로우 스펙
1.  **Initial Load:** LAI 점수: `N/A` (혹은 낮은 초기값). $X_{Pain}$: 높은 값으로 표시되며 경고 아이콘(⚠️)이 활성화됨. 그래프는 불안정한 상태를 유지하며, "데이터 수집 중" 텍스트가 오버레이됨.
2.  **User Action (슬라이더 조작):** 사용자가 변수 A를 조정하면 $\rightarrow$ **[단계 1: 계산 로딩]** 모든 지표에 '계산 중...' 애니메이션이 나타남. $X_{Pain}$ 값이 즉시 업데이트되며, 그 변화 추이에 따라 그래프의 기울기가 미묘하게 반응함.
3.  **System Response (LAI Update):** 계산 완료 후 $\rightarrow$ **[단계 2: 로직 증명]** LAI 점수와 손실 예상액이 오렌지 코랄 색상으로 전환되며 카운트업됨. 그래프 라인이 매끄럽고 강력하게 우상향하는 애니메이션을 보여주며, Storytelling 영역의 문구가 '위험 인식 $\rightarrow$ 솔루션 제시'로 즉시 변화함.
4.  **Hover/Tooltip:** 모든 슬라이더와 지표 위젯에 마우스를 올리면 해당 수치가 **비즈니스 관점에서 의미하는 바(예: Traffic 10% 증가는 곧 매출 OOO 증가 예상)**가 부연 설명되어야 합니다.

## 🎨 디자인 시스템 컴포넌트 활용
*   **Typography:** System Title (H2/H3)는 Sans-serif, 본문은 Serif 계열을 사용하여 '기술적 정확성'과 '인간적인 신뢰감'의 대비를 이끌어냅니다. [근거: 자율 사이클 메모리]
