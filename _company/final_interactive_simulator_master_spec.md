# 📊 D.AAL DESIGN 인터랙티브 시뮬레이터 마스터 스펙 (V1.0 최종 확정)

## 🎯 프로젝트 목표 및 핵심 메시지
이 시뮬레이터는 고객에게 **'단순한 웹사이트 제작 비용'**을 판매하는 것이 아니라, **'운영 시스템의 신뢰성 확보를 통한 예측 가능 손실 방지액(Loss Avoidance)'**이라는 가치를 판매합니다.

*   **핵심 지표:** Loss Avoidance Index (LAI)
*   **판매 메시지:** "귀사의 현재 비즈니스 운영 방식은 $X$만큼의 잠재적 손실을 안고 있습니다. D.AAL DESIGN 시스템 구축 시, 이 손실을 최소화하고 $Y$ 이상의 지속 가능한 성장 로직(MRR/LAI)을 확보할 수 있습니다."
*   **사용자 경험 목표:** 사용자가 자신의 현재 상황(Pain Point)에 대한 '공포'를 느끼게 하고, 우리 솔루션이 그 공포를 해소하는 '안도감 및 기대감'을 느끼도록 유도합니다.

---

## ⚙️ 시스템 플로우 다이어그램 (User Journey Map)
**총 3단계의 명확한 흐름으로 설계됩니다.**

1.  **[Step 0: 진입/Pain Point 인식]** → 사용자가 자신의 현재 문제를 인지하게 합니다.
2.  **[Step 1: 데이터 입력 및 계산 요청]** → 필수 데이터를 입력하고, 시스템이 LAI를 계산하도록 유도합니다. (가장 중요)
3.  **[Step 2: 결과 제시 및 행동 유도]** → LAI와 손실 방지액을 수치로 보여주며, 구독/서비스 플랜으로 연결합니다.

## ✨ 섹션별 인터랙티브 컴포넌트 스펙 상세 명세서

### 1️⃣ [Step 0: 히어로 & Pain Point 인식]
*   **목표:** 사용자에게 "당신은 현재 측정되지 않은 리스크를 안고 있다"는 인식을 심어주는 것.
*   **컴포넌트:** `Current State Loss Visualization` (필수)
    *   **유형:** 데이터 시각화, 애니메이션 기반.
    *   **상호작용:** 스크롤에 따라 '이상적인 성장 곡선(Uptrend Curve)'과 대비되는 '불규칙하고 끊어지는 현재의 손실 흐름' 그래프가 표시되어야 합니다. (시각적 충격 유도)
    *   **데이터/텍스트:** "일반 웹사이트는 이 데이터를 측정할 수 없습니다." 라는 경고 문구와 함께, **측정되지 않은 변수(Untracked Variable)**를 상징하는 빈 공간 또는 깨진 데이터 패킷 이미지를 배치합니다.

### 2️⃣ [Step 1: 핵심 시뮬레이터 (LAI 계산) - 인터랙티브 코어]
*   **목표:** 사용자가 스스로 데이터를 입력하게 만들고, 시스템의 '지능적인' 계산 능력을 믿게 만드는 것.
*   **구성 요소:** `Input Panel` (좌측/상단), `Calculation Output Area` (우측/메인).

#### 💾 Input Panel 컴포넌트 스펙
| 필드 이름 | 유형 | 필수 여부 | 제약 조건 및 가이드 | 데이터 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **월 평균 웹 트래픽 (A)** | 숫자 입력 (Slider) | O | 최소 100명, 최대 50,000명. 기본값: [평균치] | 계산의 분모 |
| **현재 목표 전환율 (B)** | 퍼센트 (%) | O | 범위: 0.5% ~ 10%. 마우스 오버 시 관련 가이드라인 제공. | 잠재적 매출 기반 |
| **핵심 리스크 발생 빈도 (C)** | 숫자 입력 (Dropdown/Slider) | O | 측정 단위: 월당 이벤트 수 (예: API 오류, 결제 지연 등). 1~5개 선택 가능. | 손실 발생률 정의 |
| **리스크별 평균 손실액 추정 ($)** | 숫자 입력 | O | 최소 $100 ~ 최대 $10,000$. 리스크 빈도(C)와 연동되어 곱셈 효과를 보여줌. | Loss Amount (L) |

#### 📈 Calculation Output Area 컴포넌트 스펙
*   **핵심 로직:** `Loss Avoidance Index = f(A, B, C, L)`
*   **UI 요소:**
    1.  **현재 예상 손실액 ($):** 사용자가 입력한 데이터를 바탕으로 계산된 '월간 잠재적 손실액'을 가장 크고 빨간색 계열로 강조합니다. (🚨 경고)
    2.  **D.AAL 솔루션 적용 후 기대 효과:** 이전에 정의된 `Growth Logic` 기반의 개선 로직(예: 자동화, 데이터 검증 시스템 등)이 어떻게 손실을 줄이는지 **단계별 플로우 차트**로 간결하게 시각화합니다.
    3.  **LAI 수치:** 최종적으로 도출되는 'Loss Avoidance Index'를 가장 중앙에 배치하고, 이 지표가 곧 고객의 **미래 안정성 점수**임을 강조합니다.

### 3️⃣ [Step 2: 결과 제시 및 전환 유도]
*   **목표:** 계산된 수치를 바탕으로 결제 행동을 자연스럽게 유도하는 것. (최종 CTA)
*   **컴포넌트:** `Growth Engine Retainer` 비교표 (현빈 정의 모델 기반)

| 티어명 | 가격 (월/년) | 핵심 가치 제안 (Focus) | LAI 대비 효과 (%) | 적합 고객 페르소나 |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1: Foundation** | $X$ / 연간 할인 적용 | 시스템 기반 구축 + 기술 부채 제거 로드맵 (Basic) | [Low - Mid] | 초기 스타트업, 최소한의 안정화가 필요한 고객. |
| **Tier 2: Acceleration** | $Y$ / 월 구독 | 예측 매출 시뮬레이터 완전 통합 + 실시간 데이터 검증 시스템 연동 (Core) | [Mid - High] | 성장 단계 진입, 구체적인 성과 측정이 중요한 SME. (**강력 추천**) |
| **Tier 3: Intelligence** | $Z$ / 맞춤 컨설팅 | AI 기반 지능형 예측 및 Loss Avoidance Index 최고 수준 관리 (Premium) | [High - Max] | 대기업, 시스템 안정화가 곧 비즈니스 자체가 되는 고객. |

*   **CTA 버튼:** 단순히 "문의하기"가 아니라, **"[LAI 수치]를 확보하는 방법 상담 신청"** 형태로 문구를 변경하여 가치를 연결합니다.
*   **추가 요소:** 결제 정보 옆에 작은 텍스트로 *"MRR 기반의 지속 가능한 투자입니다."*를 배치합니다.

## 💡 디자인 시스템 및 스타일 가이드 (Design System Guide)

### Color Palette
*   **Primary (신뢰/시스템):** `#0A1931` (Deep Navy - 핵심 배경, 신뢰감) [근거: Self-RAG]
*   **Accent A (성장/돈의 흐름):** `#FF6B3D` (Orange Coral - 강조, 수익 연결) [근거: Self-RAG]
*   **Danger (손실/경고):** `#C72424` (Deep Red - 손실액 시각화) [근거: Writer 비교표]
*   **Neutral:** `#F0F4F8` (Light Gray - 배경, 여백 확보)

### Typography
*   **Headline (H1/H2):** Pretendard Bold / 36px 이상 (강한 비즈니스 의지 표현)
*   **Body Text:** Pretendard Regular / 16px (가독성 최우선)
*   **Data/Metrics:** Monospace Font (예: JetBrains Mono) - 수치화된 데이터의 신뢰성을 높임.

### Interaction Principles
1.  **데이터 흐름 강조:** 모든 계산 결과는 **'어디서(Input) $\rightarrow$ 어떻게(Logic) $\rightarrow$ 얼마나($Output$)'**로 이어지는 플로우를 명시적으로 보여주어야 합니다. (애니메이션 활용 권장).
2.  **대비 효과 극대화:** 'Before State' (Pain Point, 회색/깨짐 효과)와 'After State' (Solution, 딥 네이비/깔끔한 시스템)의 시각적 대비를 가장 강력하게 사용합니다.
