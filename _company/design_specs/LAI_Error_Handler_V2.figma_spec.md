# 📐 LAI 인터랙티브 시뮬레이터 오류 처리 컴포넌트 (최종 승인 V2.0)

## 1. 목표 및 원칙 [근거: Designer Self-RAG]
*   **목표:** 단순히 에러를 표시하는 것이 아니라, 사용자에게 문제의 원인을 명확히 설명하고(Why), 다음 단계로 나아갈 수 있는 행동 지침(How)을 제공한다.
*   **톤앤매너:** Deep Navy 배경 위에서 전문적이고 신뢰감 있는 경고 톤 유지. (❌ 혼란 야기, 감정적 대응 금지).

## 2. 구조 및 레이아웃 (Desktop View 기준)
1.  **아이콘/제목 영역:** 심각도에 따른 아이콘(⚠️ 또는 🚨)과 사용자 친화적인 제목 배치.
2.  **메시지 본문 영역:** [원인] - 어떤 부분이 잘못되었는지 간결하게 설명. [해결책] - 사용자가 취해야 할 구체적 행동 제시.
3.  **CTA 영역:** 반드시 '재시도'와 '도움 요청/문의하기' 두 가지 옵션을 제공하며, 재시도는 메인 액션으로 강조한다.

## 3. 상태별 세부 스펙 (State-Specific Specs)
| 코드 | 사용자 제목 예시 | 시각적 가이드라인 | CTA 메시지 |
| :--- | :--- | :--- | :--- |
| **400** | 잘못된 데이터 입력 또는 요청입니다. | 🟡 경고(Warning) 아이콘, Amber 계열 테두리. | "데이터를 확인하고 재시도하기" (재입력 유도). |
| **412** | 필수 조건 미충족으로 처리가 불가능합니다. | 🔴 심각(Critical) 아이콘, Red 계열 테두리. | "계정 설정 및 결제 정보를 업데이트해주세요." (정보 수정 유도). |
| **500** | 시스템 오류가 발생했습니다. 잠시 후 다시 시도해 주세요. | 🚨 최고심각(Alert) 아이콘, Red/Dark Gray 조합. | "시스템 재시도"와 함께 [고객센터 문의] 버튼을 배치하여 지원 채널 제공. |
