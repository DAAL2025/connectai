# 🗺️ D.AAL DESIGN 최종 통합 사용자 여정 흐름도 청사진 v2.0

## 🎯 목적
랜딩페이지 방문자(잠재 고객)가 '단순히 정보를 얻는 것'을 넘어, **D.AAL의 시스템에 가치를 느끼고 비용 지불을 결정**하기까지의 모든 단계별 경험과 인터랙션을 정의합니다. 이 문서는 디자인/개발팀의 최종 구현 체크리스트입니다.

## 👤 페르소나 (Target Persona)
*   **이름:** 김대표
*   **상황:** 기존 웹사이트로만 운영 중이며, 매출 데이터가 불분명하고 지속적인 성장에 대한 불안감을 느낀다.
*   **핵심 니즈:** '예쁜 디자인'보다 **'매출을 예측하고 안정화시키는 방법'**에 대한 구체적 근거를 원한다.

## 🔄 사용자 여정 단계 (The Flow States)

### State 1: 진입 및 문제 인식 (Awareness & Pain Point)
*   **Trigger:** 랜딩페이지 접속 (Hero Section 로드).
*   **목표 경험:** "우리 회사의 문제는 단순한 디자인이 아니라, 시스템적인 문제입니다."라는 공포감/인식 유도.
*   **필수 UI 요소:**
    *   H1: 강력하고 비전 제시적 헤드라인 ("단순 웹사이트를 넘어, 성과를 측정하는 운영 시스템") [근거: Self-RAG]
    *   Pain Point 시각화: 기존 방식의 문제점(기술 부채, 데이터 분산)을 깨진/어두운 톤으로 보여주기. [근거: Self-RAG]

### State 2: 솔루션 이해 및 가치 측정 (Solution & Value Proposition)
*   **Trigger:** Pain Point를 인지한 후, D.AAL의 로직(Growth Logic)을 접함.
*   **목표 경험:** "D.AAL은 문제를 해결하는 시스템적 접근법을 가지고 있다."라는 신뢰 구축.
*   **필수 UI 요소:**
    *   **핵심 섹션:** '성장 로직 설계 프로세스'를 데이터 플로우 다이어그램으로 시각화 (3단계: Audit $\rightarrow$ Logic $\rightarrow$ Build). [근거: Self-RAG]
    *   **강조 인터랙션:** **데이터 흐름(Flow of Money & Data)**을 오렌지 코랄(#FF6B3D)로 강조하며, 로직 단계가 핵심임을 시각적으로 각인.

### State 3: 구체적 행동 유도 및 비교 (Comparison & Consideration)
*   **Trigger:** D.AAL의 가치에 설득되어 '비용'을 고려하기 시작함.
*   **목표 경험:** "저런 시스템이 나에게 필요하며, 이 비용은 단순한 지출이 아니라 투자가 된다."라는 합리적 판단 유도.
*   **필수 UI 요소:**
    *   Growth Tier 비교표: 단순히 기능 비교가 아닌, **'Outcome(결과)'** 중심으로 비교해야 함 (예: '단순 전시 $\rightarrow$ 성장 곡선 그래프'). [근거: Self-RAG]
    *   **핵심 인터랙션:** 결제 섹션 진입 시, 가격을 보여주기 전에 **'월간 수익 예상 시뮬레이터'**를 실행하도록 유도. (사용자가 직접 숫자를 입력하게 만듦). [근거: Self-RAG]

### State 4: 전환 및 신뢰 확보 (Conversion & Trust)
*   **Trigger:** 시뮬레이터를 통해 긍정적인 예측값을 얻음 $\rightarrow$ CTA 버튼 클릭 직전.
*   **목표 경험:** '지금 결정해야 한다'는 긴급성(Urgency)과 확신을 느낌.
*   **필수 UI 요소:**
    *   CTA: "시스템 감사 요청" (가장 낮은 장벽의 첫 액션).
    *   Footer/Trust Badge: 제휴 파트너 로고 슬라이더 및 '24시간 비즈니스 운영 시스템'과 같은 강력한 가치 문구 반복 노출.
