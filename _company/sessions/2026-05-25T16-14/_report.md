CEO님의 지시사항을 반영하여, 컨설팅적 권위와 개발 용이성을 최우선으로 고려한 단일 버전의 '손실 비용 시뮬레이션 위젯' 최종 디자인 스펙을 확정하겠습니다.

가장 효과적인 조합은 **비교형 대시보드(Comparative Dashboard)** 형태입니다. 이 구조는 단순 그래프보다 데이터 항목을 분리하고, 각 지표에 명확한 라벨과 단위('원', '%')를 부여할 수 있어 학술적 권위와 개발팀의 구현 난이도 측면에서 가장 우수합니다.

아래 스펙은 Figma 컴포넌트 기반으로 설계되었으며, CSS/React 환경에서 바로 개발할 수 있도록 구조화된 가이드라인을 제공합니다.

# 📊 최종 디자인 스펙: 손실 비용 시뮬레이션 위젯 (V3.0)
**[위젯 목표]**: 사용자의 현재 상태(Before)와 D.AAL DESIGN의 솔루션을 적용한 잠재적 미래(After) 간의 재정적 격차(Failure Cost)를 수치적으로 충격 요법을 통해 인지시키고, 컨설팅 서비스가 필수적임을 느끼게 한다.

**[전체 구조 (컨테이너)]**: 학술 보고서 느낌의 모듈형 3단 레이아웃 (총 너비: 1200px 기준)
*   **배경:** `#F7FAFC` (약간의 여백감과 전문성을 주는 밝은 회색)
*   **컨테이너 스타일:** `box-shadow: 0 4px 15px rgba(10, 25, 49, 0.08);` (깊이감을 주어 중요한 섹션임을 강조)

## 1. [요약 지표] Failure Cost Gauge (최상단 액션 유도 영역)
가장 먼저 사용자 시선을 사로잡는 핵심 요약 구간입니다.
*   **레이아웃:** 세 개의 큰 카드(Card Grid, 3열) 배치.
*   **핵심 컴포넌트: 실패 비용 게이지 (Failure Cost Gauge)**
    *   **형태:** 단순한 수치 제시가 아닌, '위험도/손실 폭'을 시각화하는 원형 그래프(Radial Progress Bar) 형태를 사용합니다.
    *   **Before 값:** 파란색 또는 회색(`#ADB5BD`) 계열로 채워져서 현재의 불안정함을 표현합니다. (예: 72%)
    *   **After 값 (잠재 개선치):** 오렌지 코랄(`#FF6B3D`) 색상으로, 도달 가능한 목표 지점을 가리킵니다. (예: 15%로 감소)
    *   **텍스트 강조:** 게이지 중앙에 **"최소 잠재 손실 비용: ₩[X]백만원"**을 가장 크게 표시합니다.

## 2. [비교 분석] 핵심 지표 비교 테이블 (Core Metric Comparison Table)
데이터의 신뢰성을 높이는 가장 중요한 영역입니다. 표 형식으로 구성하되, 단순히 숫자를 나열하는 것이 아니라 '지표 → Before/After'로 명확히 분리합니다.

*   **컴포넌트 타입:** 반응형 데이터 테이블 (`<table class="comparison-data">`)
*   **헤더 (Header):** 딥 네이비 배경, 흰색 텍스트. [구분 지표] | [현재 상태 (Before)] | [예측 개선치 (After)]
*   **데이터 행(Row) 구조:** 각 행은 하나의 측정 가능한 비즈니스 지표를 다룹니다.

| 구분 지표 (Metric) | 현재 상태 (Before - Pain Point) | 예측 개선치 (After - Solution Potential) | 시각화/설명 (Developer Note) |
| :--- | :--- | :--- | :--- |
| **1차 유입 채널 최적화율** | `[A]`% (회색 톤, ↓ 화살표) | `[B]`% (오렌지 코랄, ↑ 화살표) | *수치 변화의 방향성*과 *정량적 개선 폭*을 함께 제시. |
| **전환 퍼널 이탈 지점** | 평균 35% 이탈 (`⚠️` 경고 아이콘) | 평균 12% 이탈 (안정된 체크 표시) | '문제 인식'에 초점을 맞춘 시각 요소. |
| **지속 가능한 매출 기여도 (MRR)** | `[C]`만원/월 (회색, 불안정한 그래프 모양) | `[D]`만원/월 (오렌지 코랄, 우상향 곡선 그래프) | 가장 중요한 지표. 단순 수치 대신 '성장 곡선'을 함께 사용해야 권위적임. |
| **기술 부채 비용 발생 예상액** | ₩200만 ~ 350만원/년 (경고 박스 디자인) | ₩50~100만원/년 (예방 가능 영역으로 축소) | '비용'이라는 단위를 명시하여 위협감을 극대화. |

## 3. [깊이 분석] 상세 근거 시각화 (Supporting Evidence Module)
가장 복잡하지만 권위를 부여하는 섹션입니다. 사용자가 "저렇게까지 과학적으로 진단해 주는구나"라는 느낌을 받도록 합니다.

*   **컴포넌트:** `Before`와 `After`의 흐름을 대조하는 **'플로우 다이어그램(Flow Diagram)'**
*   **레이아웃:** 좌/우 분할 (Split View)
    *   **[좌측: Current State - Before]**: 복잡하고 엉킨 와이어프레임 이미지와 함께, 데이터 흐름이 막히는 지점(Bottleneck)을 **붉은색 점선과 'X' 표시**로 강조합니다.
        *   *캡션:* "데이터가 새고 있는 구간: 예측 불가능한 운영 구조"
    *   **[우측: Designed State - After]**: 깔끔하게 정리된 화살표와 데이터 흐름(Data Flow) 다이어그램을 배치하고, 모든 연결 지점을 **오렌지 코랄(`#FF6B3D`)의 견고한 선**으로 처리합니다.
        *   *캡션:* "최적화 로직: 예측 가능한 성장 엔진 구축"

### 🛠️ 개발자 전달용 에셋 가이드라인 (Developer Handoff Specification)

개발팀이 구현할 때 필요한 필수 정보만 정리했습니다.

1.  **컬러 팔레트:**
    *   Primary Background: `#F7FAFC`
    *   Deep Navy (Authority): `#0A1931` (헤더, 텍스트 강조)
    *   Accent Color (Loss/Gain Emphasis): `#FF6B3D` (오렌지 코랄, 상승/개선 지점)
    *   Warning Color (Before/Failure): `#ADB5BD` (중간 회색, 경고 표시 및 현재 상태)

2.  **폰트:** 시스템 기본 산세리프 폰트 사용 권장 (예: Pretendard, Noto Sans KR). 학술적이고 가독성 높은 느낌을 유지합니다.

3.  **반응형 고려사항 (Responsiveness):**
    *   데스크톱(1200px)에서는 위 스펙대로 3단 그리드를 사용합니다.
    *   태블릿/모바일 환경에서는 **[요약 지표]**는 1열로 쌓고, **[비교 분석 테이블]**은 세 개의 컬럼이 순차적으로 아래에 배치되는 구조(Stacking)를 적용해야 합니다.
