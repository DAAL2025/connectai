# 📊 Mini-Audit Funnel: 상품 비교 시스템 UI/UX 명세서 (V2.0)
**[목표]** 진단된 손실 비용($FC$)을 시각적, 감정적으로 사용자에게 충격 요법으로 전달하고, D.AAL DESIGN의 솔루션(유료 서비스)이 유일한 해결책임을 납득시키는 것.

## 1. 전체 디자인 토대 (Global Elements)
| 요소 | 상세 명세 | 기술 적용 지침 | 근거 |
| :--- | :--- | :--- | :--- |
| **톤앤매너** | 권위적, 과학적(Scientific), 긴급함(Urgent). 마치 금융 기관의 리스크 보고서 같은 느낌. | 전체 배경은 다크 그레이 또는 딥 네이비(#0A1931)를 사용하되, 핵심 데이터만 밝게 강조. | Self-RAG [Pain Point 섹션] |
| **주요 컬러** | **Danger/Warning:** 오렌지 코랄 (#FF6B3D) (돈, 경고). **Background:** 딥 네이비 (#0A1931). **Text:** 화이트 또는 라이트 그레이. | $FC$ 수치와 위험 지표에만 오렌지 코랄을 사용하고, 일반 텍스트는 채도를 낮춥니다. | Self-RAG [MRR 관련 강조] |

## 2. 핵심 컴포넌트 명세: $FC$ 경고 게이지 (Financial Cost Warning Gauge)
이 컴포넌트는 페이지 로딩 직후(Above the Fold) 가장 눈에 띄어야 하며, 사용자가 진단받은 금액($total\_fc$)을 즉각적으로 시각화해야 합니다.

### 2-1. 구조 및 배치
*   **위치:** 상품 비교 섹션 최상단 (H1/H2 아래).
*   **형태:** 가로로 긴, 반원 또는 직사각형 형태의 게이지 바(Gauge Bar).
*   **데이터 연동 지점:** `product_service.py`에서 계산된 `data.total_fc_estimate` 값을 받습니다.

### 2-2. 인터랙션 및 로직 (가장 중요)
| 상태 | 조건 (Input Data) | 시각적 변화/애니메이션 | 카피라이팅 강조 |
| :--- | :--- | :--- | :--- |
| **Danger Zone** (위험) | $FC$ > 500만원 | 게이지 바가 오렌지 코랄 색상으로 가득 차오르며, 배경에 미세한 '경고 플리커(Flicker)' 효과 발생. | "현재 비즈니스가 감내하고 있는 잠재적 손실액은 **최소 월 $X,XXX** 입니다." (크게 강조) |
| **Caution Zone** (주의) | 100만원 < $FC$ $\le$ 500만원 | 게이지 바가 오렌지/옐로우 그라데이션으로 차오름. 경고 플리커는 약하게 유지. | "운영 로직 최적화를 통해 **최소 월 $X,XXX** 의 손실을 줄일 수 있습니다." (가능성 제시) |
| **Optimal Zone** (안정) | $FC$ $\le$ 100만원 | 게이지 바가 녹색(Green) 또는 파란색으로 채워지며, 애니메이션 효과 없이 안정적인 느낌. | "시스템 운영이 안정화되어 재무적 리스크 관리가 이루어지고 있습니다." (최상의 상태로 포장) |

## 3. 상품 비교 테이블 명세 (The Comparison Matrix)
단순한 표가 아닌, '문제점 $\to$ 해결책'의 대비 구조를 가져야 합니다.

### 3-1. 레이아웃 및 구성
*   **열 구성:** [항목] | [기존 방식/일반 웹사이트] | [D.AAL ENGINE (솔루션)]
*   **시각적 강조:** '기존 방식' 열은 **회색(Glitch Effect)**과 깨진 파선으로 처리하여 무능력한 느낌을 주고, 'D.AAL ENGINE' 열은 딥 네이비 배경에 깔끔하게 정돈된 데이터 흐름처럼 보이게 합니다.

### 3-2. 항목별 비교 (Key Features)
| 비교 항목 | 일반 웹사이트 (Before State) | D.AAL ENGINE (After State) | 시각적 처리 지침 |
| :--- | :--- | :--- | :--- |
| **수익 예측** | 정적 페이지 / 단순 기능 나열 | **실시간 MRR/FC 연동 대시보드** | 그래프 형태 (Uptrend Curve, 오렌지 코랄)로 반드시 시각화. |
| **데이터 처리** | 수동 관리 / 분산 저장소 의존 | 통합 API Gateway 및 자동 리포트 시스템 구축 | 데이터 플로우 다이어그램으로 표현하며, 화살표는 빛나는 느낌을 줍니다. |
| **리스크 대응** | 문제 발생 시 사후 대처 (Reactive) | $FC$ 기반 선제적 예측 및 경고 모듈 (Proactive) | '⚠️' 아이콘과 함께 재무 리스크가 사라지는 애니메이션 효과를 삽입합니다. |

## 4. 최종 CTA 섹션 명세: 구매 유도와 논리 완성
상품 비교표 아래에 위치하며, 위기감과 솔루션을 연결하는 결정적 순간입니다.

### 4-1. 'Growth Tier' 재정의
*   **제목:** "최소한의 투자로 최대의 운영 리스크를 제거하십시오."
*   **카드 구성:** 기존의 기능 나열 방식 대신, **[위험도] $\leftrightarrow$ [투자 비용] $\leftrightarrow$ [예상 $FC$ 감소액]** 구조로 카드를 재구성합니다.

### 4-2. 가격 및 결제 버튼 (Critical Element)
*   단순한 '구매하기' 버튼이 아닙니다. **[MRR 기반 투자 시작하기]** 같은 문구를 사용해야 합니다.
*   버튼 클릭 시, Modal Window가 뜨면서 "선택하신 플랜은 최소 월 $X$의 운영 리스크를 해결하는 비용입니다."와 같이 재무적 논리를 상기시켜야 합니다.
