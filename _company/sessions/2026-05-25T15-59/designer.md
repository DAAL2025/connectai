### 💡 [손실 비용 시뮬레이션 위젯] 최종 디자인 스펙 (3가지 버전)

**공통 원칙:**
1.  **헤드라인:** "귀사의 비즈니스 운영 시스템 진단 결과: 잠재적 재정 손실 예측"을 항상 최상단에 배치하여 무게감을 부여합니다.
2.  **컬러 사용:**
    *   `#0A1931` (Deep Navy): 배경, 제목, 권위성 있는 텍스트.
    *   `#FF6B3D` (Coral Orange): 해결책, 절감 가치(Avoidance Value), 주요 CTA 요소.
    *   회색/빨강 계열: 현재 상태, 리스크, 손실액 (Pain Point).

---

#### 🥇 Version 1: 재정적 충격 모델 (The Direct Financial Impact Model)
**[주요 목표]**: 가장 빠르고 강렬하게 '돈'의 문제를 인식시켜 즉각적인 행동을 유도합니다. 심리적 충격에 최적화되었습니다.
**[컨셉]**: 좌우 대비(Before/After)를 명확한 수치와 기호로 분리하고, 숫자에 그림자나 굵은 테두리를 적용하여 중요도를 강조합니다.

| 요소 | 디자인 스펙 및 레이아웃 지시 | 근거 (Self-RAG / 컨텍스트) |
| :--- | :--- | :--- |
| **레이아웃** | 2단 구조 (좌: 현재 리스크, 우: 개선 후 예측). 중앙에 큰 화살표(`→`)를 배치하여 흐름을 강제합니다. | *[Writer/Researcher 데이터]* Failure Cost의 직접적인 비교 필요성. |
| **Before State (현재)** | 배경색: 연한 회색(Light Grey) 또는 미세한 Glitch 효과 적용. 텍스트 색상: 어두운 빨간색(`Dark Red`). <br>**수치화:** `$5,000 ~ $20,000+`와 같은 숫자를 **크고 볼드하며** 경계선 처리합니다. (실제 손실액처럼 보이게) | *[Self-RAG]* Pain Point 섹션의 공포감 극대화 방식 차용. |
| **After State (개선 후)** | 배경색: 깨끗한 흰색 또는 은은한 딥 네이비 그라데이션. 텍스트 색상: 딥 네이비. <br>**수치화:** 절감 가치를 나타내는 금액을 `Coral Orange`로 크게 표시하고, '절감액'이라는 라벨링을 붙입니다. | *[Self-RAG]* MRR 관련 수치는 오렌지 코랄(#FF6B3D)로 강조하여 수익과 연결. |
| **CTA** | "손실 방어 로직 설계 및 진단 받기" 버튼을 배치하며, 이 버튼이 가장 눈에 띄는 `Coral Orange` 색상이어야 합니다. | *[Growth Engine]* '시스템'을 통한 문제 해결 제시. |

#### 🥈 Version 2: 성장 곡선 모델 (The Time-Series Growth Curve Model)
**[주요 목표]**: 감성적/논리적으로 접근하여, 단순히 돈이 새는 것을 넘어 **‘시간과 기회’의 손실**을 강조합니다. 가장 학술적인 느낌입니다.
**[컨셉]**: 그래프(Graph)를 핵심 시각 요소로 사용하며, 현재 상태는 낮은 평야에 머물고 있는 곡선으로 표현하고, D.AAL DESIGN 도입은 급격한 우상향 곡선으로 보여줍니다.

| 요소 | 디자인 스펙 및 레이아웃 지시 | 근거 (Self-RAG / 컨텍스트) |
| :--- | :--- | :--- |
| **레이아웃** | 가로형 그래프 차트(X축: 시간, Y축: 예측 매출/안정성). 중앙에 'Curvature Change'를 나타내는 주석 박스를 배치합니다. | *[Self-RAG]* Growth Tier 비교표에서 사용된 성장 곡선 개념 활용 및 전문성 강화. |
| **Before State (현재)** | 그래프 라인: 낮은 경사도(Flat/Wobbly Line). 색상: 회색 계열. <br>**설명:** "기술 부채로 인한 성장의 평탄화" 또는 "예측 불가능한 수익 흐름." 이 구간의 끝 지점에 '리스크 경고' 마커를 찍습니다. | *[Researcher]* 트래픽 급증에 따른 서비스 다운 (Downtime) 리스크와 연결하여 설명 가능. |
| **After State (개선 후)** | 그래프 라인: 가파른 우상향 곡선(Sharp Uptrend). 색상: `Coral Orange`로 부드럽게 그라데이션 처리. <br>**설명:** "시스템 로직 설계 기반의 예측 가능한 매출 성장 궤도." 이 곡선의 높이를 'Loss Avoidance Value'와 연결합니다. | *[Self-RAG]* '지속 가능한 성장 로직(Growth Logic)'을 시각적으로 증명. |
| **CTA** | 그래프 아래에 "성장 궤도 재설계 및 진단 받기" 문구를 배치하며, 버튼은 곡선과 동일한 `Coral Orange`를 사용합니다. | *[Designer Self-RAG]* 'MRR 예측' 개념을 CTA와 연동하여 시각화 (Small Iconography). |

#### 🥉 Version 3: 시스템 구성 요소 모델 (The Component Breakdown/Risk Map Model)
**[주요 목표]**: 기술적 지식이 있는 사용자(CTO, 개발팀 리더 등)에게 최적입니다. 문제의 원인을 '시스템 구조'로 분해하여 제시함으로써 권위성을 확보합니다.
**[컨셉]**: 3~4개의 상자형 모듈(Module Box)을 배치하고, 각 상자가 어떤 기능을 담당하며, 그 기능이 실패했을 때 어떤 재정적 파급효과를 가져오는지 도식화합니다.

| 요소 | 디자인 스펙 및 레이아웃 지시 | 근거 (Self-RAG / 컨텍스트) |
| :--- | :--- | :--- |
| **레이아웃** | 4개의 상자 모듈을 그리드 형태로 배치하고, 상자들 사이에 '시스템 연결성' 화살표를 사용합니다. 중앙에 큰 제목 "최소한의 결함이 최대의 손실을 만듭니다."와 같은 문구를 삽입합니다. | *[Researcher]* 실패 유형(결제 트랜잭션 오류, 데이터 무결성 등) 자체를 구조적으로 분해하여 활용. |
| **Module 1 (Payment)** | 제목: "결제 파이프라인 안정성". 리스크 지표: '트랜잭션 누락률'. 손실액 표시: $5k~$7.5k/월. | *[Researcher]* No. 1 실패 유형을 전면에 배치하여 가장 큰 위협임을 각인시킵니다. |
| **Module 2 (Data)** | 제목: "리드 데이터 무결성". 리스크 지표: '데이터 활용도'. 손실액 표시: $10k~$20k+/월. | *[Researcher]* No. 2 실패 유형을 배치하여 마케팅 파이프라인의 핵심 위협을 강조합니다. |
| **Module 3 (Scale)** | 제목: "운영 연속성(Downtime)". 리스크 지표: '가동률(Uptime)'. 손실액 표시: $500~$2,000/시간. | *[Researcher]* No. 3 실패 유형을 배치하여 물리적 안정성을 위협 요소로 제시합니다. |
| **CTA** | "통합 시스템 감사 보고서 받기" 버튼을 사용하며, 이 버튼이 세 모듈의 리스크를 동시에 해결할 수 있는 '최종 진단'임을 강조합니다. | *[Self-RAG]* 모든 문제를 포괄하는 종합 컨설팅 서비스라는 메시지 강화. |
