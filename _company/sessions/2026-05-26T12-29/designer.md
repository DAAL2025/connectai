## 🧱 섹션별 상세 UX/UI 브리프

### 1. Hero Section: The Hook & Problem Definition
**목표:** 사용자의 주의를 즉시 사로잡고, 웹사이트가 '단순한 페이지'가 아님을 인지시킨다.
*   **H1 (헤드라인):** "당신의 비즈니스는 지금, 보이지 않는 돈으로 새고 있습니다."
    *   *(강조:* 문장 전체를 굵게 처리하고, 특히 **"보이지 않는 돈으로 새고 있습니다"** 부분은 `Warning Red`로 하이라이트합니다.)
*   **서브 헤드라인:** "일반적인 웹사이트 제작 방식으로는 예측 불가능한 운영 리스크($FC$)를 방치하게 됩니다."
    *   *(강조:* '운영 리스크'와 '$FC$'에 시스템 아이콘(⚠️)과 함께 배치하여 개념을 시각화합니다.)
*   **CTA:** "무료 Mini-Audit 실행하기" (Deep Navy 배경, Cyan Blue 버튼).

### 2. Pain Point Section: The Diagnosis (The 'Before')
**목표:** 사용자가 현재의 방식에 문제가 있음을 직관적으로 느끼게 한다. 재무적 불안감 조성.
*   **비주얼 요소:** **'실패 비용 시뮬레이터 1단계 진단'** 섹션으로 전환됩니다.
*   **디자인 특징:** 이 섹션은 *일반적인 웹사이트의 데이터 흐름을 가정한 다이어그램* 형태로 보여줍니다.
    *   **시각화:** 일반 사이트의 데이터 플로우는 **끊기거나(Broken)**, **누수되는 듯한 파선/와이어프레임 스타일**로 표현합니다.
    *   **텍스트 강조:** "데이터가 흐르지 못하고 정체되거나", "결제 과정에서 이탈하는 구조적 결함" 등 실패의 원인을 명시합니다.
    *   **인터랙션:** 사용자가 마우스 커서를 '누수 지점'에 올리면 (Hover), 해당 부분이 붉은 경고(`Warning Red`)와 함께 깜빡이는 애니메이션이 발생해야 합니다.

### 3. Mini-Audit Core Section: The Financial Shock Moment
**목표:** 이 섹션의 핵심입니다. 사용자가 직접 숫자를 입력하여 재무적 충격(Financial Shock)을 경험하게 만듭니다.
*   **UI 구성:** 인터랙티브 계산기 형태 (Input Field + Output Display).
*   **상호작용 1: Input 단계:** 사용자에게 "현재 월평균 트래픽", "전환율 예측치", "객단가" 등의 가짜 질문을 제시합니다. 입력 필드는 일반적인 웹 양식처럼 보입니다.
*   **상호작용 2: Calculation & Shock (핵심):**
    1.  사용자가 값을 입력하고 '분석' 버튼을 누릅니다.
    2.  일반적인 로딩 애니메이션 후, **[진단 결과]**가 등장합니다.
    3.  **시각적 연출:** 계산 결과가 단순 텍스트로 나오지 않습니다. 페이지 중앙에 **대형 경고 게이지 (Gauge)**가 나타나야 합니다. 이 게이지는 현재 예상 손실 비용($FC$)을 시각적으로 보여주며, 바늘이 `Warning Red` 영역의 높은 수치(예: "월 $X,XXX")를 가리키도록 강렬하게 애니메이션 됩니다.
    4.  **사운드/햅틱 피드백 (추가 고려):** (개발팀과 논의) 결과 제시 시 낮은 톤의 경고음이나 진동을 넣어 재무적 긴급성을 극대화합니다.
*   **결과 메시지:** "현재 시스템으로는 월 최소 $\text{KRW } X,XXX$ 규모의 잠재 손실 비용($FC$)이 발생할 위험이 높습니다." (강력한 문장으로 마무리)

### 4. Solution Section: The Transformation (The 'After')
**목표:** D.AAL DESIGN만이 이 문제를 해결할 수 있음을 시스템적으로 증명한다.
*   **비주얼 요소:** **Before/After 비교 애니메이션**을 사용합니다.
    1.  화면 좌측(BEFORE): Pain Point Section에서 보았던, 누수되고 끊긴 파선의 다이어그램이 천천히 회색으로 사라집니다.
    2.  화면 우측(AFTER): D.AAL의 시스템 로직(`Growth Logic`)을 상징하는 **오렌지 코랄(#FF6B3D) 데이터 플로우 다이어그램**이 매끄럽게 나타나며, 모든 선과 화살표가 완벽하게 연결되어 원활하게 흐르는 애니메이션(Data Flow Animation)이 재생됩니다.
    *   *(핵심 메시지:* "우리는 결함을 가려주는 것이 아니라, 시스템 자체를 재설계합니다.")
*   **CTA:** **[Phase 2] 성장 로직 설계 및 MRR 모델링** 섹션으로 자연스럽게 유도하며, 다음 단계의 상세 내용을 보여줍니다.
