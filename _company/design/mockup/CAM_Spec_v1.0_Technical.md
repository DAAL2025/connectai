# 🚨 Critical Alert Module (CAM) 개발 명세서 V1.0\n\n## 🎯 목표 및 역할\n*   **목표:** $FC$ 값을 단순 수치가 아닌, '즉각적인 재무적 위기감'으로 변환하여 사용자 행동을 유도하는 인터랙티브 게이지 구현.\n*   **핵심 원칙:** 데이터 $\to$ 시각적 스트레스(Visual Stress)로의 전환.\n\n## 🎨 UI/UX 컴포넌트: AlertGauge\n*   **위치:** Mini-Audit Funnel 최종 결과 페이지 최상단.\n*   **구조:** 게이지 바, 위기 레벨 마커, $FC$ 수치 Headline.\n\n### 1. 상태 정의 및 트리거 (State Machine)\n| FC 범위 | Level Name | 주요 색상 코드 | 애니메이션 효과 | 개발 Trigger | \n| :---: | :---: | :---: | :---: | :---: | \n| $0 \sim 500$ | Safe | Primary Blue/Orange Accent | None / Gentle Data Flow\n| $501 \sim 1,200$ | Warning | Amber/Yellow (`#FFC300`) | Jitter Effect (Subtle)\n| $> 1,200$ | Crisis | Deep Red (`#B32C2C`) | Flicker + Glitch Filter\n\n### 2. 기술 명세: CSS & JavaScript\n**A. 데이터 바인딩:**\n*   `data-fc-value`: 백엔드 API `/api/v1/mini-audit/fc_result`에서 전송된 최종 $FC$ 값 (Number).\n*   **JS 로직:** `updateGauge(value, level)` 함수는 이 값을 받아 게이지의 Width와 Class를 변경.\n\n**B. 핵심 CSS 스펙 (Critical State):**\n```css\n/* Crisis Active Class */\n.alert-gauge.is-crisis {\n  background: radial-gradient(circle at 50% 10%, rgba(255, 0, 0, 0.3) 0%, #B32C2C 70%);\n  box-shadow: 0 0 40px rgba(179, 44, 44, 1); /* 강렬한 발광 효과 */}\n/* Flicker Animation */\n@keyframes flash {\n  0%, 100% { opacity: 1; } \n  50% { opacity: 0.9; filter: brightness(1.1) contrast(1.2); }\n}\n```\n**C. 필수 인터랙션 스펙:**\n*   **Load Animation (JS):** $FC$ 값이 로드되면, `transform: scaleY(0)`에서 시작하여 1.5초에 걸쳐 `scaleY(1)`로 부드럽게 올라오면서 채워지는 효과 적용.\n*   **Crisis Transition:** Warning $\to$ Crisis 전환 시, 색상 변화는 즉각적이지만 (CSS transition time 0.3s), 게이지 전체가 **`@keyframes flash`**를 반복 실행하며 긴급성을 고조시킴.\n\n## 💡 개발 가이드 및 주의사항\n1.  **사운드 디자인 Hook:** $FC$ 값이 Warning $\to$ Crisis로 전환되는 순간, 사용자 경험을 극대화하기 위해 낮은 주파수의 경고음(Low-frequency Alert Tone)이 재생되어야 합니다.\n2.  **Accessibility:** 게이지의 색상 대비와 중요 텍스트는 시각 장애인 접근성 기준을 충족하도록 반드시 점검해야 합니다."
